📄 Contratos de evento

O caminho normal é pela aba Eventos: em cada orçamento há o botão “✍️ Gerar contrato para assinar”, que aproveita o que o cliente já preencheu. Use o formulário abaixo só para contrato que não veio de um orçamento.

O contrato é gravado ANTES de existir link. O texto fica congelado e ganha um código único (hash). O link é de uso único e vale 30 dias. Assinado é assinado: não dá para reemitir nem editar.

📷 Ler documento por foto
Cartão CNPJ, comprovante, print. A foto é lida e usada só para preencher os campos acima — não fica guardada nos nossos servidores. Ela é enviada à Anthropic (EUA) para leitura; por política do fornecedor, pode ficar até 30 dias no sistema dele para controle de abuso. Envie apenas documento que o titular mandou para este fim. Sempre confira os campos antes de gerar o contrato.

Histórico dos contratos antigos

Os contratos emitidos antes deste registro viviam só no link do orçamento e nunca foram gravados. Dá para trazê-los para cá como histórico. Eles entram marcados como “importado” e sem link de assinatura — porque não foram assinados aqui, e o painel não vai fingir que foram. Para colher assinatura de um deles, gere um contrato novo pelo orçamento.
